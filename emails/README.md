# Secuencia de Emails

Plantillas HTML para GoHighLevel (GHL) con nombres ordenados.

## Asuntos sugeridos por plantilla

- `1-bienvenida.html` -> `Hemos recibido tu solicitud de auditoría`
- `2-problemas.html` -> `Si te pasa esto, no eres el único`
- `3-error.html` -> `El error más caro al aplicar IA en empresas`
- `4-dudas.html` -> `Las 5 dudas más comunes antes de automatizar`
- `5-testimonios.html` -> `Lo que dicen empresas que ya automatizaron`
- `6-enfoque.html` -> `Por qué trabajamos así (y no de otra forma)`
- `7-limites.html` -> `Lo que NO vas a conseguir con nosotros`
- `8-motivo.html` -> `No va solo de tecnología`
- `9-origen.html` -> `Cómo empezó Pau Solutions`
- `10-cierre.html` -> `Si no es el momento, no pasa nada`
- `11-confirmacion.html` -> `Tu auditoría está confirmada`
- `12-recordatorio.html` -> `Tu auditoría sigue pendiente de agendar`

## Nota de uso en GHL

- Secuencia principal recomendada: `1` a `10`.
- Plantillas variables según evento: `11-confirmacion` (cuando hay cita) y `12-recordatorio` (si no se agenda o según tu lógica).
